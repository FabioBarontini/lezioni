Protocollo e porta sono concetti diversi ma strettamente collegati quando osserviamo un servizio di rete.

PROTOCOLLO

Le regole

Definisce come vengono formati e interpretati i messaggi e come i sistemi devono comportarsi durante la comunicazione.

PORTA

L'accesso logico

Permette di distinguere servizi diversi sullo stesso dispositivo.

HTTP / HTTPS

Porta tipica: 80 / 443.

HTTP

HTTP è il protocollo usato per trasferire risorse web. La porta 80 è quella tipicamente associata a HTTP.

GET /index.html HTTP/1.1

HTTPS

HTTPS è HTTP protetto tramite TLS. La porta 443 è quella tipicamente associata al servizio web HTTPS.

TLS → HTTP protetto

DNS

DNS permette di risolvere nomi di dominio in indirizzi IP. Il traffico DNS è comunemente associato alla porta 53.

Da ricordare: protocollo = regole della comunicazione; porta = punto di accesso logico a un servizio.
